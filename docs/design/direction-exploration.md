# Visual direction exploration

**Audience / task:** Job seekers arriving with a vacancy need a clear, single-pass path to an inspectable CV. Operate mode, not a marketing landing page. Preserve the existing form, routes and async states. The incumbent category default is a dashboard form plus generic blue cards; its opposite, an immersive CV-paper metaphor, risks making work harder. Neither is the starting direction.

## Seven grounded systems (resonance order)

1. **Application proof sheet:** a print-proof layout with the vacancy as source copy and the CV as the working proof; distinctive margin annotations can explain edits without another wizard. Familiarity risk: editorial paper aesthetics are common in AI resumes.
2. **Desk register:** a practical paper register of active applications with crisp rows and marginal status markers; good at sessions, but the creation form risks looking administrative.
3. **Indexed folio:** an open work folder with a narrow indexed task rail, one broad writing surface, and clear file tabs for generated artifacts. It makes the job input and the applicant's result feel like two states of the same work, not separate products. Selected by Impeccable seed 7489d09c and explicitly chosen by the owner before UI implementation.
4. **Typesetter's mark-up:** a production proof with corrections and version marks; strong for CV edits but may imply automatic copy changes too strongly.
5. **Field manual:** a concise numbered guide with structured controls and evidence notes; useful for first-run but can become didactic for repeat users.
6. **Application logbook:** chronological entries and completion stamps; strong history vocabulary but weak authoring workspace.
7. **Library index card:** compact cross-references between company, CV profile and provider; excellent retrieval, too small-scale for long job descriptions.

## Dealt challenger verdicts against indexed folio

On the two axes *job-seeker identification* and *task clarity*: the acetate reference manual is **competitive** on clarity (but its section-hue complexity strains identification); design annual plate, cassette J-card, vertical video feed, gardens map, split-flap board are **declined** on both axes when translated to long-form CV input and review. The assigned folio borrows no motifs from them. It raises its own discipline with explicit, legible cross-references (manual), stronger full-sheet composition (annual), finite task progression (cassette), one dominant active task (feed), recognisable section geography (map) and status that can be read at a glance (split-flap). These are constraints on its own system, not visual costumes.

The owner selected indexed folio over the category-standard alternative. No route or production style changed before selection.
