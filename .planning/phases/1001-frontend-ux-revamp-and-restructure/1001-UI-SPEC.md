## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, pill toggle internal padding, model-badge padding |
| sm | 8px | Action button row gap, form field gap, cover letter actions gap, margin-top after hints |
| md | 16px | Default element spacing, section padding, form field stacking gap, sidebar header padding |
| lg | 24px | Main content horizontal padding, action button padding (0 24px) |
| xl | 32px | Main content top padding, cover-letter-section margin-top |
| 2xl | 48px | Loading/spinner vertical padding, gap-analysis-section margin-top |
| 3xl | 64px | Page-level major section breaks (reserved; not currently used) |

Exceptions:
- Touch target minimum for primary sidebar button: 44px height (`.new-job-btn` — already implemented)
- Tab navigation bar height: 44px (new component, must match sidebar button for visual consistency)
- Pill toggle button height: 32px (selectors — ModelSelector, ToneSelector, CreativitySlider)
- Standard action button height: 40px (all buttons in action bars, cover letter actions)
- Label hint text margin: 6px (between label and toggle; kept as-is — not a spacing token, internal only)

Source: codebase scan of all component scoped CSS.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 14px | 600 (semibold) | 1.2 |
| Hint / Meta | 12px | 400 (regular) | 1.4 |
| Heading (section) | 20px | 600 (semibold) | 1.2 |

**Notes:**
- Exactly 4 sizes: 12, 14, 20, and the existing sidebar micro-text at 11px (cv-info-detail, model-badge) is reserved only for metadata badges — do not use for interactive copy.
- Exactly 2 weights: 400 (body, hints, meta, prose) and 600 (labels, headings, buttons, active states).
- Body text in prose areas (cover letter editor, job text): line-height 1.6 (established in `.cover-letter-editor` and `.job-text-content`).
- Tab labels use 14px / 600 — same as button labels.

Source: App.vue :root (14px base), ModelSelector, CoverLetterSection, JobDetailView scoped CSS.

This is new for Phase 1001 (D-02). JobDetailView switches from vertical stacking to 3 tabs.

**Tab bar spec:**
```

```

```
height: 44px
padding: 0 20px
background: transparent
border: none
border-bottom: 2px solid transparent
color: #6b7280
font-size: 14px
font-weight: 600
cursor: pointer
```

## Shared Selector Component Contract

Per D-05: ModelSelector, ToneSelector, and CreativitySlider must be unified to a single shared CSS class set or a base component.

**Recommended approach (Claude's Discretion):** Extract a shared CSS utility class set — `.pill-group`, `.pill-option`, `.pill-option--active`, `.pill-option--disabled` — into a shared `selector.css` file imported by each component. This avoids a new base component abstraction that changes prop contracts. All three selectors apply these classes identically.

**Unified selector anatomy:**
- `.pill-group` — the outer container (inline-flex, gap 4px, padding 4px, bg #fff, border #e2e8f0, border-radius 6px)
- `.pill-option` — each button (height 32px, padding 0 16px, bg transparent, color #111827, font-size 14px, weight 600, border none, border-radius 4px)
- `.pill-option--active` — selected state (bg #2563eb, color #ffffff)
- `.pill-option--disabled` — unavailable option (color #6b7280, cursor not-allowed)

**Label:** `.field-label` — 14px, weight 600, color #111827, margin-bottom 6px.

**Hint:** `.field-hint` — 12px, color #6b7280, margin-top 6px.

## Interaction States

All interactive elements must implement these states consistently:

| State | Treatment |
|-------|-----------|
| Default | As defined in button hierarchy above |
| Hover | Color/border change, 150ms ease transition |
| Active/pressed | Visual feedback (momentary) — browser default or opacity 0.9 |
| Disabled | opacity 0.6, cursor not-allowed — no hover effect |
| Loading | Button label changes to "{action}ing...", button disabled during operation |
| Focus | Browser default focus outline preserved — do not remove outline |
| Error | ErrorBanner component above content; no inline field-level errors in this phase |
