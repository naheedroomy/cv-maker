2. Create `frontend/src/stores/cvStore.ts` — Pinia setup store:
   - State: `cv` (ref of BaseCV | null), `loading` (ref boolean), `saving` (ref boolean), `uploading` (ref boolean), `error` (ref string), `uploadProgress` (ref string — for status text like "Parsing PDF...")
   - `fetchCv()`: GET /api/cv/me via apiFetch. If has_cv=true, set cv.value. If false, set cv.value = null.
   - `saveCv()`: PUT /api/cv/me with cv.value as JSON body. Set saving=true/false around the call. On success, show nothing (caller handles). On error, set error.
   - `deleteCv()`: DELETE /api/cv/me. On success, set cv.value = null.
   - `uploadPdf(file: File)`: POST /api/cv/upload as multipart/form-data.
     - Create FormData, append file as "file"
     - Use apiFetch with the FormData body (do NOT set Content-Type header — let browser set multipart boundary)
     - Set uploading=true, uploadProgress="Uploading PDF..."
     - On response: if success=true, set cv.value = response.cv. If success=false, set error = response.message.
     - Set uploading=false
   - `createEmptyCv()`: Create a blank BaseCV with empty contact, empty summary, empty arrays. Set cv.value to it. (For manual CV creation without upload.)
   - Export all state and actions

3. Create `frontend/src/components/PdfDropZone.vue`:

     - Hidden file input (accept=".pdf,application/pdf") triggered by clicking the zone
     - When idle: show upload icon text "Drop your CV (PDF) here or click to browse"

     - Validate dropped/selected file is PDF before emitting
   - Styling: dashed border (#d1d5db), rounded corners, padding 48px, hover/dragover blue highlight border (#2563eb), centered text
