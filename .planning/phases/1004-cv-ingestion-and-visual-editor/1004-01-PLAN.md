2. Create `core/cv_parser.py` with:

   a. `_pdf_to_images(pdf_bytes: bytes, dpi: int = 200) -> list[bytes]` — Uses `fitz` (pymupdf):
      - `doc = fitz.open(stream=pdf_bytes, filetype="pdf")`
      - For each page: `pixmap = page.get_pixmap(dpi=dpi)`, append `pixmap.tobytes("png")`
      - Returns list of PNG byte arrays
      - Close doc in finally block

   b. `_ocr_images(images: list[bytes], client: genai.Client, model: str) -> str` — Pass 1 (OCR):
      - System instruction: "You are an OCR engine. Extract ALL text from this CV/resume image. Preserve the structure (headings, bullet points, dates, contact info). Return the extracted text faithfully — do not summarize, rephrase, or omit anything."
      - For each image, create a `genai_types.Part` with inline_data (mime_type="image/png", data=base64-encoded image bytes)
      - Send all page images in a single request as a list of Part objects
      - Return `response.text`

   c. `_structure_text(ocr_text: str, client: genai.Client, model: str) -> BaseCV` — Pass 2 (Structuring):
      - Reuse the prompt pattern from `cv_converter.py _CONVERT_PROMPT` but with `ocr_text` instead of `cv_text`
      - Add the same JSON schema as _CONVERT_PROMPT
      - Parse response text: strip markdown fences, json.loads(), BaseCV.model_validate()
      - Retry up to 3 times on parse/validation failure

   d. `async def parse_pdf_to_base_cv(pdf_bytes: bytes) -> BaseCV` — Main entry point:
      - Gets GEMINI_API_KEY from env var `os.environ.get("GEMINI_API_KEY", "")` — this is the inhouse key per D-01
      - If no key, raise RuntimeError("GEMINI_API_KEY not configured for CV parsing")
      - Creates `genai.Client(api_key=api_key)`
      - model = "gemini-2.5-flash-lite" (per D-01)
      - Calls `_pdf_to_images()` via `asyncio.to_thread`
      - Calls `_ocr_images()` via `asyncio.to_thread`
      - Calls `_structure_text()` via `asyncio.to_thread`
      - Returns validated BaseCV
      - All three sync steps wrapped in asyncio.to_thread since they do I/O

   Use standard logging: `logger = logging.getLogger(__name__)`
   Import `_extract_json` from `core.pipeline` for JSON extraction (already handles markdown fence stripping).

  Per D-01: Use Gemini 2.5 Flash-Lite for both passes. Use inhouse GEMINI_API_KEY from .env (not per-user key).
  Per D-01: PDF only — no DOCX handling.

2. Create `backend/routers/cv.py` with APIRouter(prefix="/cv", tags=["cv"]):

   a. `POST /upload` — accepts `UploadFile` parameter named `file`:
      - Validate file.content_type is "application/pdf" — return 400 if not
      - Read file bytes: `pdf_bytes = await file.read()`
      - Validate size < 10MB — return 400 if exceeded
      - Call `await parse_pdf_to_base_cv(pdf_bytes)` (from core.cv_parser)
      - Convert result to YAML: `yaml.dump(result.model_dump(), ...)`
      - Save to DB: UPDATE users SET base_cv_yaml=? WHERE id=? (using user["id"] from get_current_user)
      - Return CvUploadResponse(success=True, message="CV parsed and saved", cv=result.model_dump())
      - On RuntimeError from parser: return CvUploadResponse(success=False, message=str(exc))

   b. `GET /me` — returns user's saved CV:
      - Query: SELECT base_cv_yaml FROM users WHERE id=?
      - If base_cv_yaml is NULL: return CvMeResponse(has_cv=False)
      - Parse YAML, validate with BaseCV.model_validate(), return CvMeResponse(has_cv=True, cv=base_cv.model_dump())

   c. `PUT /me` — saves edited CV:
      - Accept request body as dict (use `body: dict` parameter)
      - Validate with BaseCV.model_validate(body) — return 422 if invalid
      - Convert to YAML: yaml.dump(validated.model_dump(), ...)
      - UPDATE users SET base_cv_yaml=? WHERE id=?
      - Return {"success": True, "message": "CV saved"}

   d. `DELETE /me` — removes user's CV:
      - UPDATE users SET base_cv_yaml=NULL WHERE id=?
      - Return {"success": True, "message": "CV removed"}

   All endpoints use `user: dict = Depends(get_current_user)` per established auth pattern.
   All DB writes use `BEGIN IMMEDIATE` per Phase 5 convention.
